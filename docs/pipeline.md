# 参数与调参记录

## 1. 光栅化

| 参数 | 值 | 说明 |
| --- | --- | --- |
| dpi | 300 | A4 得 2481×3508，够 6 寸冲印 |
| 页 | 0 | 单页 PDF |

## 2. 裁切定位

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 匹配算法 | TM_CCOEFF_NORMED | 对亮度整体偏移不敏感 |
| 多尺度 | 页面 0.5/0.75/1/1.5/2/3，模板 0.25~0.9 | 截图被压缩过，尺寸不等于实际 |
| 阈值 | 0.55 | 低于此分说明截图和页面不是同一内容 |

实测 11 张截图得分 0.879~0.994。

## 3. 放大

Lanczos4 ×2.5 + `addWeighted(1.2, blur(1.5), -0.2)`，比双三次更少出现"糊边"。

## 4. 生成模型

| 项 | 值 |
| --- | --- |
| 模型 | `doubao-seedream-5-0-pro-260628`（保真）/ flash（快、便宜但易同脸化） |
| 尺寸 | 2K |
| 输入 | base64 data URI（也可传公网 URL） |
| 输出 | 临时 URL，24 小时有效，需要立刻下载 |

### 提示词模板（保真关键）

```
修复这张老照片：清除纸面的霉斑、水渍与划痕，去掉四周波浪花边纸框。
严格保留人物原有的五官相貌、脸型、嘴型与眉眼，不得美化、不得改变长相，
不要添加原图没有的物品或装饰。
```

反例（会崩）：

- "修复并提升画质" → 模型自由重绘，单人像会长出耳环、发夹
- "让照片更清晰漂亮" → 会把 60 岁的人修成 30 岁
- 只写"保持人物特征" → 合影里的人被修成同一张脸

## 5. 后处理参数

| 场景 | blur | contrast | grain | lift |
| --- | --- | --- | --- | --- |
| 普通人像 | 1.1 | 0.03 | 2.2 | 1 |
| 风景 / 远景合影 | 1.4 | 0.06 | 2.4 | 2 |

上色版：饱和度 ×0.72，与黑白版混合 18%，整体 ×0.95 +10，再叠 σ=1.8 颗粒。

## 6. 迭代次数的教训

对同一张脸连续跑 GFPGAN：

- 第 1 次：五官变清晰，仍是本人
- 第 2 次：眉毛变浓、嘴唇变厚，开始漂移
- 第 3 次：**已经不是同一个人了**

结论：**重建只做一遍**。多跑不是"更清晰"，是"更不像"。

## 7. 各方案实测（32GB 内存 / i5-13400F / 无可用 GPU）

| 方案 | 耗时 | 清污能力 | 保真度 |
| --- | --- | --- | --- |
| DiffBIR v2.1 CPU 分块 | 2~4 小时/张 | 无 | 中 |
| GFPGAN 单独 | 1 秒/张 | 无 | 高 |
| LaMa 蒙版修补 | 10 秒/张 | 需人工蒙版 | 中 |
| Seedream flash | 5 秒/张 | 强 | 低 |
| Seedream pro | 35 秒/张 | 强 | 中高 |

最终选择：**放大 + Seedream pro + 柔化**，11 张约 20 分钟。
